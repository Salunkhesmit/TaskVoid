# TaskVoid

### Organize Tasks. Stay Focused.

TaskVoid is a minimal, dark-themed task management website that brings everyday task organization and focused work sessions into a unified workspace.

Designed with simplicity and clarity in mind, it combines practical task management with a dedicated focus system to encourage a more structured and productive workflow.

## Features

- **Task Management** — Create, organize, and manage everyday tasks through a simple interface.
- **Focus Sessions** — Dedicated sessions designed to help maintain concentration while working.
- **Distraction Management** — Support for managing selected distractions during active focus sessions.
- **Minimal UI** — Clean, modern, and aesthetically balanced dark-themed interface.
- **Responsive Design** — Adaptable layout for different screen sizes.
- **Simple Workflow** — Straightforward interactions without unnecessary complexity.

## Focus System

TaskVoid includes an integrated focus utility that complements its task management functionality.

Users can initiate structured work sessions while managing access to selected distractions, helping create a more controlled and focused working environment.
